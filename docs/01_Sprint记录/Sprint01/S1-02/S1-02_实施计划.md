## 8. TDD、影响面与测试隔离门禁

- P01 先提交可观察 red；S01 核验失败原因；S02 只做使冻结行为 green 的最小实现。
- implementation 必须从实际 changed paths 独立重建 `discovered_impact_set`，与设计 `IMP-01..06` 比较；差集非空返回 design-plan。
- `executed_regression_set` 覆盖新文件、affected test_mode、full suite 和文档/Skill 静态验证，记录工作目录、解释器、退出码和直接结果。
- 测试使用脱敏地址字符串且零数据库连接；若实际代码或测试新增连接/可达性检查，`database_test_isolation_result=violation` 并停止，不得连接生产库取证。
- 每例独立临时源、实例缓存和 cleanup；新增 fixture 必须与测试代码同 commit 且由 Git 跟踪。
