## 5. 冻结 DAG 与恢复

```text
S00(sol: input-gate / target / first-sync / records)
  -> P01(luna wave 1: red + direct delegates + green)
  -> S01(sol: integrate / gates / issue commit / Sprint publish)
```

- 初始 ready 只有 S00；S00 完成后 singleton wave P01 ready。
- P01 writer terminal 后，Sol 校验 target、base、changed paths、commit 和 validation；accepted 后集成并证明其 tip 是 Issue HEAD 祖先。
- S01 只在 P01 处置唯一、无活动 package writer且 Sol 是唯一 Issue writer时 ready。
- 恢复只读取阶段总结、plan version、固定 target、最后完成 unit 和 Git HEAD；禁止重建单元、owner、wave 或 validation。

P01 spawn 前在 `S1-01_实施记录.md` 写入：`action_key=Sprint01:S1-01:implementation:P01`、`stable_task_name=sprint01_s1_01_p01`、`task_mode=package`、`plan_version=S1-01-plan-v1`、target、base HEAD、owned files、validation、`canonical_agent_id=pending`。spawn 后绑定唯一 Agent ID。
