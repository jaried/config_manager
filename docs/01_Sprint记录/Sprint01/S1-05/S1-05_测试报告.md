## failures

Windows 主验证无失败。

Linux 候选和基线均存在同一个既有平台失败：

```text
tests/01_unit_tests/test_config_manager/test_config_file_protection.py::
TestConfigFileProtection::test_complex_windows_paths_handling
```

基线已经以相同断言失败；本次变更没有修改该文件、路径实现或任何生产代码，因此属于既有跨平台测试失败，不是
S1-05 新增失败。

验证过程中还出现过三类基础设施失败，均在独立验证分支解决，未进入成果差异：缺少 `PYTHONPATH`、完整套件
缺少既有依赖 `psutil`、changed-path 比较基线范围过宽。这些失败不涉及产品或正式测试行为。
