### 失败与并发一致性

- `_autosave_intent_lock` 只保护批次根段的合并、摘取和清空，不跨文件 I/O 或 watcher lock；`FileWatcher._state_lock` 只保护 watcher 自身 path、mtime、internal flag 和轮询分类，两把锁不存在嵌套反向获取。
- progress-only 成功路径在 watcher guard 内完成主文件原子替换与 watermark 确认；False 或 exception 均由 guard `finally` 清理本次 internal flag，且不推进旧 watermark。
- 普通根段、mixed 根段或无键来源不会进入 progress-only 分支；显式 `save()` 不消费 autosave intent，继续使用通用保存和 best-effort backup。
- Windows 上冻结 affected 集合的一个外部文件变化测试按既有平台条件 skip；新增 deterministic watcher 测试直接覆盖外部 callback 与锁释放关系，当前 Reviewer 复跑通过。该 skip 未掩盖 S1-04 新行为失败。
