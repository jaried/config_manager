## 1. 输入与阶段边界

本设计展开已批准的双文件配置行为：`base_config_path` 是只读通用层，`config_path` 是可写专用层。实施只消费冻结方案、现有仓库事实和下列 Implementation Items，不新增业务、公开接口、依赖、数据格式或验收取舍。

## 2. 目标行为与验收闭环

`get_config_manager(config_path, *, base_config_path=None, watch=True, auto_create=False, autosave_delay=None, first_start_time=None, test_mode=False)` 在提供 `base_config_path` 时按“通用层 → 专用层覆盖”读取，保存只写专用层与通用层的差集。

- 无 `base_config_path`：既有单文件加载、保存、备份、watch、缓存和兼容行为保持不变。
- 两层 merge：mapping 递归合并；专用层的列表、tuple、标量整体替换；输入不被修改。
- 保存：显式 save、autosave、初始化回写和 reload 相关保存入口只写差集；通用层 bytes/hash 保持不变；`__type_hints__` 只保留差集路径。
- 通用层加载失败：在读取 overlay、处理 `auto_create`、生成 `first_start_time`、派生 paths 和任何保存入口之前短路并返回加载失败；overlay 缺失不创建，已有 overlay bytes 不变。
- `watch=True` 与 `base_config_path` 同时出现时抛出 `ValueError("base_config_path requires watch=False")`。
- `test_mode=True` 只复制或创建专用层；base 从原路径只读；测试序列化呈现合并后的完整数据。
- 缓存身份包含规范化的专用路径、通用路径、模式/测试标识和 `first_start_time`；无 base 时保留既有单文件 key 形状。
- 初始化备份只备份专用 `config_path`；通用文件不进入保存或备份写入口。

## 3. 生产路径与数据不变量

### 3.1 加载

`initialize` 将 `base_config_path` 传入 `_load`。有 base 时先以 `auto_create=False` 加载通用层，再加载 overlay 并合并；通用层 failure state 在上述所有副作用前 fail-closed。无 base 时继续既有单文件路径。

### 3.2 保存与提示

`save`、`_delayed_save`、`_save_config_only` 和初始化回写均以合并数据相对 base 计算差集，并按现有格式和 `FileOperations` 写入专用层。`first_start_time`、派生 `paths` 和专用覆盖项只进入差集；合并视图的提示在保存时过滤为差集路径。

### 3.3 reload、watch 与 test_mode

`reload` 重读两层并重新建立合并视图。公开入口拒绝 watch 与 base 的冲突。测试模式只复制专用层，base bytes 不变；缓存 lookup/create 使用同一包含规范化 base 的 key producer。

## 5. 错误语义

- 通用层不存在或解析失败：返回加载失败；不创建缺失 overlay、不修改已有 overlay、不派生初始化字段、不进入保存入口。
- 保存候选验证失败：沿现有 ADR-002 语义返回 `False`，旧专用文件保持不变。
- watch 冲突：入口立即抛固定 `ValueError`，不创建实例、不写文件。

## 6. 测试设计与回归矩阵

- 纯函数：标量覆盖、嵌套合并、列表替换、相等键省略、空 mapping 省略、输入不变。
- 加载：标准与原始格式的 base/overlay merge；base 缺失与损坏均 fail-closed；四种失败组合均验证 overlay 不创建或 bytes/hash 不变。
- 保存：显式 save、progress-only 与普通 delayed save、初始化 finally 回写、初始化专用备份；每项验证 base bytes/hash 不变和完整 merged serialization。
- 提示与初始化：`first_start_time`、paths 和提示差集只进入 overlay。
- 入口与缓存：无 base 兼容、watch 冲突文本、规范化 base cache key、不同 base 隔离和同组合复用。
- test_mode：只复制专用层，base 原位不变，序列化数据包含合并结果。
- 回归：本票相关 focused、affected、full unit、Ruff、compileall 和 diff-check 结果写入测试报告；无关 skip 不作为本票门禁。
