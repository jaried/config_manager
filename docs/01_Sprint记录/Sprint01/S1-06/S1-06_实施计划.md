## I02 required behavior / test mapping

| 行为 | 生产 caller | 固定测试证据 |
| --- | --- | --- |
| base/overlay hints 按键合并，overlay 同键优先 | `_load` 的 layered loader | base-only、overlay-only、同键 override、嵌套 dotted hint |
| merged snapshot 同时消费合并 data/hints | `_get_serializable_data` / `get_serializable_data` | 公开序列化接口同时断言数据键和提示键 |
| base 缺失/损坏 fail-closed | `initialize` 在 overlay load、auto_create、first_start_time、paths 前短路 | overlay 存在/缺失 × `auto_create=True/False` 四组合；返回 None、文件 bytes |
| 显式 `save` | `save` | overlay 差集、base bytes/hash 前后相同 |
| progress-only/普通 autosave | `_delayed_save` → `_save_config_only` 或 `save` | 两种 pending intent 分支分别断言 overlay 与 base bytes/hash |
| 初始化回写 | `initialize` finally → `_save_config_only` | 派生 first_start_time/paths 只进入 overlay，base hash 不变 |
| 初始化备份 | `_perform_initialization_backup` | backup path 源于 overlay，base bytes/hash 和 base mtime 不变 |

## 停止与失败

- 真实依赖、本票测试门禁、用户决定和一小时实施窗口是硬门禁。
- base 读失败、候选保存失败和既有回归失败保留真实证据；在批准范围内修复，范围外只记录，不扩大改动。
- Runtime/HOST deterministic error 保留 `code/reason/evidence`，同一 Run/action readback 后等待能力恢复；不伪造状态或 receipt。
